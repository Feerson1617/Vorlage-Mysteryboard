# RC2-Prüfnachweise

Die vollständigen Konsolenprotokolle sind als Text abgelegt; für Git wurden ausschließlich nachlaufende Leerzeichen entfernt. Die unveränderten Rohprotokolle, vollständigen Playwright-Berichte, PNGs und Screenshots liegen zusätzlich im RC2-Abnahmepaket unter `evidence/`.

`rc2-first-pass.txt`, `rc2-second-pass.txt` und `rc2-third-pass.txt` dokumentieren die Entwicklung des zusätzlichen Abnahmeskripts (Importattribut, Drag-Zeichenreihenfolge und Auswahl des Richtungsfelds). `rc2-fourth-pass.txt` ist der abschließende erfolgreiche Durchlauf. `full-check.txt` enthält die vollständig erfolgreiche bestehende Regression einschließlich 57 Datentests und 96 Browsertests.
